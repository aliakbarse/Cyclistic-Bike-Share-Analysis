# Raw data (not versioned)

The 12 monthly Divvy trip-data files (September 2025 - August 2026, about 1.2 GB extracted) are not stored in this repository.

**To reproduce**
1. Download the monthly `YYYYMM-divvy-tripdata.zip` files for `202509` to `202608` from the Divvy system data page: https://divvybikes.com/system-data
2. Keep the originals unmodified in this folder.
3. Extract each ZIP to `02_Raw_Data/extracted/` (one CSV per month).

The data is published by Lyft Bikes and Scooters, LLC under the Divvy data license agreement; read it before reuse. See `docs/project_management/05_Licensing_Privacy_Accessibility.md`.
